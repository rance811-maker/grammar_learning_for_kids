# Grammar Quest 账号系统设置说明

账号系统基于 **Supabase Auth**（邮箱 + 密码登录），密码找回邮件由 Supabase 原生发送。
学习数据存在 `gq_profiles` 表，靠行级安全(RLS)保证每个人只能读写自己的数据。
（表名用 `gq_profiles` 是为了避开项目里可能已存在的同名 `profiles` 表。）

## 一次性设置（在 Supabase 控制台操作）

### ① 建表
左侧 **SQL Editor → New query**，把 `docs/supabase-setup.sql` 整个粘贴进去，点 **Run**。
（可重复运行：已有的表和用户数据原样保留，只补上缺的部分。Supabase 若提示「包含破坏性操作」，指的是脚本里的 `drop policy`——删的是权限规则、紧接着原样重建，不是数据。）

### ② 配置站点网址（找回密码邮件要用）
左侧 **Authentication → URL Configuration**：

- **Site URL** 填正式域名：`https://grammar-quest.net/`
  （Netlify 上 primary domain 是裸域，`www` 会自动重定向过来，所以这里填裸域）
- **Redirect URLs** 逐条 Add URL，把下面几个都加上：

```
https://grammar-quest.net/**
https://www.grammar-quest.net/**
https://grammar-quest-pet.netlify.app/**
https://rance811-maker.github.io/grammar_learning_for_kids/**
```

> 找回密码 / 确认邮件里的链接会跳回这些网址，不在白名单里就会被拒绝。
> 旧的两个地址暂时保留：老用户手里可能还有指向旧站的邮件链接，
> 等确认没人再从旧地址进来了再删。

### ③（建议）关闭邮箱确认，让小朋友注册后能立刻玩
左侧 **Authentication → Providers → Email**：
- 把 **Confirm email** 关掉（OFF）。

这样注册后直接进入，不用先去邮箱点确认。
（如果保持开启也能用，只是注册后要先去邮箱点一下确认链接才能登录。）

## 使用方式

- **没登录**：只能看，不能用。看到的是「示例同学」的进度（`js/demoState.js`，只在内存里，不落盘、不上传），每页顶上有「这是示例数据」横条；点练习、发现、写作、摸底、家长专区会先看到注册引导（`js/views/gate.js`）。
- **注册**：名字（昵称）+ 家长邮箱 + 密码（≥6 位）。这台设备上以前（还能免注册使用时）做过的练习会带进新账号；新账号回首页自动进摸底。
- **登录**：邮箱 + 密码。登录后切换成账号里云端保存的进度，多设备同步。
- **忘记密码**：在登录框填入注册邮箱 → 点"忘记密码？" → 收邮件 → 点链接 → 设置新密码。

## 关于发信额度

Supabase 自带的邮件发送有较低的频率限制（适合小规模使用）。
如果以后用户变多、发信不够用，可在 **Authentication → Emails / SMTP Settings**
里配置自定义 SMTP（如 Resend、Gmail 等）来提高额度。

## 备注

- 旧版自建账号表 `kids` 和 `kid_register` / `kid_login` / `kid_load` / `kid_save` 四个函数
  已不再被网站代码使用，但还留在数据库里，而且未登录也能调用。确认不需要后可以删掉。
- `js/supabaseConfig.js` 里是项目 URL 和公开 key（publishable key 本就可公开，
  真正的安全由 RLS 保证）。

## 作文批改（网站免费提供，每个账号每天 3 篇）

- 写作任务交上去后，没配自己 key 的用户走云函数 `gq-review-writing`（`supabase/functions/gq-review-writing/`），
  用网站的 Claude key（模型 Sonnet 4.6）逐句批改；每个账号每天（北京时间）最多 3 篇，计数在 `gq_ai_usage` 表
  （`docs/ai-review-setup.sql`）。批改失败不算次数。
- 家长在「家长专区 → 学习设置 → AI 服务」配了自己的 key 的，浏览器直连 AI，不限次数，也不经过云函数。
- **需要在 Supabase 控制台配一次密钥**：Edge Functions → Secrets → 新增 `ANTHROPIC_API_KEY`（填 Anthropic 控制台里的 API key）。
  没配的话，交作文时提示「批改服务暂时没开通」。
- 改每日篇数：改 `supabase/functions/gq-review-writing/index.ts` 里的 `DAILY_LIMIT`，重新部署云函数。
- 改批改提示词：云函数的 `review.ts` 和前端的 `js/writingCoach.js` 各有一份（后者给自备 key 的家长用），两边一起改。
